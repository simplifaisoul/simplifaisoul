## 🚀 Flagship Projects

### 🏛️ [Osiris](https://github.com/simplifaisoul/osiris) — Open-Source Palantir Alternative
> *Real-time global intelligence dashboard. No API keys. One-click Vercel deploy.*

The single-pane-of-glass for global situational awareness. Track **5,000+ aircraft**, **2,000+ satellites**, live conflict zones, seismic events, and financial markets — all on a unified dark-ops map interface.

- ✈️ Commercial, private, military & bizjet flight tracking via `adsb.lol`
- 🛰️ Orbital satellite tracking with SGP4 propagation via CelesTrak TLE data
- 💥 GDELT-powered global conflict aggregation & risk scoring
- 📡 GPS jamming detection via NACp value analysis
- 🗺️ Right-click region dossier — country profile, head of state, Wikipedia summary
- 📈 Defense markets ticker — RTX, LMT, NOC, GD, BA, PLTR + oil prices
- 🌑 Day/night solar terminator overlay
- 🔴 Ukraine frontline via DeepState Map
- **Zero API keys required. 100% open data.**

`Next.js 15` `MapLibre GL` `TypeScript` `Vercel Serverless` `OSINT`
